How N-Queens Backtracking Works

  1. Start from the first row.
  2. Try placing a queen in each column.
  3. Check whether the position is safe.
  4. If safe, move to the next row.
  5. If no position is possible, backtrack.
  6. Remove the previous queen.
  7. Try another position.
  8. Continue until all queens are placed.
A queen cannot share:
  • Same row
  • Same column
  • Same diagonal

Pseudocode

function solve(row):

    if row == N:
        record solution
        return

    for col = 0 to N-1:

        if position is safe:

            place queen

            solve(row + 1)

            remove queen

Complexity

Time ComplexityO(N!)
Space ComplexityO(N)

Backtracking abandons a partial placement the moment it conflicts with an earlier queen, so entire branches of the search space are skipped instead of being generated and checked. This prunes the tree far below the NN or N! arrangements a brute-force search would examine.
